# DMG Background Design Instructions

## Background Image Requirements
- Size: 540x380 pixels (as configured in package.json)
- Format: PNG
- Background color: Light gray or white (#f5f5f5)

## Visual Elements to Include

### Main Installation Instruction
- Large arrow pointing from app icon to Applications folder
- Text: "Drag YouTube Music Downloader Pro to Applications"

### Security Warning Notice
- Small warning icon (⚠️)
- Text: "Security warning is normal - see installation guide"

### Visual Layout
- App icon position: x=130, y=220
- Applications folder position: x=410, y=220
- Arrow should curve from left to right
- Text should be in a readable font (14-16px)

## Color Scheme
- Background: #f5f5f5 (light gray)
- Text: #333333 (dark gray)
- Arrow: #007AFF (blue)
- Warning text: #FF9500 (orange)

## Notes
This file serves as design specification for creating the actual dmg-background.png file.
The image should be created using design software (Photoshop, Figma, etc.) or generated programmatically.
